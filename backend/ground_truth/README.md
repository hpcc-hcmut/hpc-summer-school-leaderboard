# Ground Truth

This directory contains instructor-facing scoring materials.

- **`*_public.json`**: These files are sample/demo materials intended to show the expected format.
- **`*_private.json`**: These are the private scoring materials used for live deployment and automated evaluation.

**⚠️ IMPORTANT ⚠️**
Do not distribute private files to students during a live event.

## Customizing the Assignment
To adapt the assignment for your own course or event, replace the following components as needed:
- Public questions
- Private questions
- Ground-truth answers
- Expected evidence paths
