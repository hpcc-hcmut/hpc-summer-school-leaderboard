# Privacy Guidelines

When using this leaderboard repository for live events, strict privacy and security practices must be maintained:

1. **Student Data**: Do not commit raw student identifiers, attendance records, or real leaderboard databases to this repository.
2. **Anonymization**: Use anonymized team names (e.g., "Team 01", "Team 02") for public results and demonstrations.
3. **Secrets**: Do not commit a production `.env` file. Any committed `.env.example` file must contain only dummy examples and placeholders.
4. **Team Tokens**: Replace real team tokens with examples in the repository. Generate new, secure random tokens for each live event.
5. **Private Materials**: Keep private question files and ground-truth materials instructor-facing. They must not be distributed to the student repository or leaked during the event.
