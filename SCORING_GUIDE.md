# Scoring Guide

This document details the scoring rubric for the HPC Summer School Mini Hackathon.

## Rubric Breakdown

The paper describes the default 100-point rubric as follows:

| Category | Max Points | Description |
|---|---|---|
| Correctness | 40 | Accuracy of the answers and analysis generated by the workflow. |
| Evidence grounding | 25 | The ability of the workflow to cite and ground its answers using provided context. |
| Agentic workflow design | 20 | The robustness, routing logic, and architecture of the LLM pipeline. |
| HPC/resource efficiency | 15 | Efficient use of Slurm resources, batching, and LLM serving limits. |
| **Total** | **100** | |

**Instructor Note**: Instructors may adjust these weights depending on course goals, but should ensure that the rubric remains transparent to students throughout the event.
